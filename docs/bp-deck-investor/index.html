PROBLEM

服务商收入 = 顾问人数
× 人均客户数

顾问产能是天花板

代运营 3k–15k 元/月、建站 2–10 万/单的生意，交付规模被顾问人头锁死。

获客钩子是手工作坊

「免费诊断」是行业验证的获客钩子（HubSpot 用它换了 400 万+ 网站评分），但服务商靠顾问手工做，2–4 小时/单。

客户的钱在流血

月烧数万广告费却转化差的企业，落地页与追踪问题的每分浪费都是现金。

付费方经济学的起点：找到对方的收入公式，我们改动的是「人均可服务客户数」这个变量。

MARKET

诚实的大小账：三层

滩头（本轮承诺）

服务商诊断工具订阅：数万级服务商 × 2–3 万/年 ≈ 低亿级人民币/年。可达成千万级 ARR 现金流生意。

扩展 1 · 行业纵深

行业知识库 + 前后对比数据资产驱动的产品溢价，随模板数与数据积累放大。

扩展 2 · 交易层期权

诊断入口 → 跨境服务撮合/抽成。服务市场年交易额百亿级。是上行期权，不在本轮承诺内。

扩展层的入场券，正是滩头积累的知识库与纵向数据——免费 grader 和通用 LLM 都不沉淀这两样。

不把 18 万亿大盘当 SAM 讲——投资人会当场拆穿。滩头小但真实，扩展是期权。诚实反而是差异化。

COMPETITION

三层夹击，各有回答

免费工具 · 上方

HubSpot Grader / PageSpeed / Ahrefs。无跨境语境、无纵向追踪、无服务闭环。

人工诊断 · 同位

同行顾问手工诊断。我们是产能杠杆，不是替代品——客户就是顾问本人。

通用 LLM · 下方

ChatGPT 直问。无事实检测层；确定检测 + LLM 解读可复现可验证。

收费只凭三样：跨境行业语境 · 前后对比数据资产 · 服务承接闭环——三者都在随每次诊断累积。

「凭什么打得过免费」是必答题，答案要具体到资产，不能是「我们体验更好」。

MOAT

数据飞轮，不是架构口号

✗ 我们不声称的

LLM+工具编排架构（可复制）· 过程可视化（一季度可抄）· 多语言（功能不是壁垒）

✓ 随每次诊断变厚的

行业知识库（案例冷启动，先发者最难抄）· 前后对比纵向数据（免费工具都不做，驱动复查留存）· 服务商网络与承接闭环（双边效应雏形）

每一次诊断都让报告更专业、数据资产更厚、服务商网络更密——这是飞轮，不是功能清单。

诚实清单策略：先承认什么不是护城河，再说什么是。投资人对「我们的 AI 是护城河」已经免疫了。
