## 0. 开场 45 秒（最强的证据前置）

大多数天使轮 pitch 停在 idea 和 PPT 阶段。本项目的三个不同：

1. **产品已建成并可用**：输入 URL + 目标市场，5 分钟生成四模块跨境出海诊断报告（网站理解、确定性检测、LLM 报告、PDF 导出、顾问问答全闭环），不是 demo 视频，是可现场实测的系统。
2. **定位经过证伪式市场研究**：我们主动验证并放弃了「终端付费诊断 SaaS」叙事（全行业诊断免费，无存活先例），转向证据更强的 B2B2B 服务商工具定位——研究过程和全部数据来源公开可查。

## 1. Q1：你怎么赚钱

### 1.1 痛点（Problem）：跨境服务商的产能与获客双瓶颈

- 外贸服务商（代运营、建站、SEO/广告代理）的收入公式 = 顾问人数 × 人均可服务客户数。顾问产能是行业天花板。
- 行业主流获客钩子是「免费网站诊断」，但靠顾问手工完成（**合理假设**：2–4 小时/单），响应慢、不可规模化。
- 客户端的痛是真实的：月烧数万广告费却转化差的企业，落地页/追踪问题的每一分浪费都是现金（research §2.2 痛点分层）。

### 1.2 解决方案（已建成，非规划）

| 能力 | 状态 |
|---|---|
| 网站定位理解（LLM 读取页面，先读懂客户生意） | ✅ 已上线 |
| 四模块确定性检测：访问加载 / 落地页转化 / 产品合规内容 / 表单追踪 | ✅ 已上线 |
| 报告生成 + 顾问问答 + PDF/HTML 独立导出 | ✅ 已上线 |
| 诊断历史、前后对比、白标、批量诊断、API | 🚧 路线图（融资后交付） |

技术架构：确定性工具做事实检测（可复现、不幻觉）+ DeepSeek LLM 做理解与生成。React + Express + PostgreSQL + Playwright，支持 Docker 私有化部署。

### 1.3 客户与付费逻辑（Beachhead）

- **首批客户**：服务 20–200 家客户的外贸代运营 / 广告代理商。
- **付费理由（付费方经济学）**：顾问手工诊断 2–4 小时/单（人力成本 150–250 元/小时）→ 平台 5 分钟出报告，月诊断 30 客户的服务商每月节省 45–105 工时 ≈ 释放 0.3–0.6 个顾问 FTE；诊断钩子 7×24 承接线索，一年多转化 1 单建站（客单 2–10 万）即覆盖全年订阅费。
- **付费能力已被市场验证**：服务商本来就买工具——孚盟 CRM 约 2 万/年、易营宝 19,800–42,800 元/年、店小秘 VIP 2,016–9,888 元/年（来源见附录）。

### 1.4 定价与单位经济

| 档位 | 定价 | 内容 |
|---|---|---|
| 基础版 | ¥499–999/月 | 不限坐席、限诊断量 |
| 专业版 | ¥2–3 万/年 | 白标报告、批量诊断、前后对比、顾问问答 |
| 白标/私有化 | +¥1 万/年起 | 品牌输出、私有部署 |

- 单次完整诊断模型 token 成本为**个位数人民币** → 毛利率 >95%，定价不受成本约束。
- 真正约束是 CAC：所以 GTM 走服务商渠道直销 + 行业口碑，不做终端投放。
- 对标 SaaS 健康线：LTV:CAC >3x、CAC 回收 <18 个月、NDR >100%（复查钩子 + 白标扩容驱动）。**当前无真实留存数据，第一批 cohort 数据将在试点期产生并回填——不编造。**

### 1.5 销售路径（GTM）

创始人直销 10–15 家服务商试点 → 案例与口碑 → 行业协会/跨境社群渠道 → 白标分销。诊断工具本身即线索入口（服务商的终端客户 = 我们的潜在客户的数据来源）。

## 2. Q2：投资人怎么赚钱

### 2.1 市场：诚实的大小账

我们不讲「18 万亿跨境电商大盘」的虚故事，讲三层：

| 层 | 规模 | 可信度 |
|---|---|---|
| 滩头 SAM：服务商诊断工具订阅 | 数万级服务商 × 2–3 万/年 ≈ 低亿级人民币/年 | 高（价格带已验证） |
| 扩展 1：行业知识库 + 数据资产驱动的产品溢价与行业纵深 | 随行业模板数与数据积累放大 | 中（待验证） |
| 扩展 2：诊断入口 → 跨境服务交易撮合/抽成（服务商与出海企业的匹配层） | 服务市场年交易额为百亿级（代运营 3k–15k/月 × 数十万企业） | 期权价值，不在本轮承诺范围内 |

**本轮融资只承诺滩头**：滩头本身可达到千万级 ARR 的现金流生意；扩展层是上行期权（optionality），其入场券正是滩头积累的行业知识库与前后对比数据资产——免费 grader 和通用 LLM 都不沉淀这两样。

### 2.2 回报与退出逻辑

- 跨境 SaaS 已有可比退出路径：店小秘（180 万注册用户、沙利文口径 34.8% 跨境用户覆盖）走完融资到规模化路径；跨境工具赛道并购活跃（ERP/营销工具被平台与服务商集团收购案例频出）。
- 若扩展 2 走通，平台型故事的估值锚从 SaaS 倍数切换为交易佣金模型。
- 诚实边界：基线存活率约 10%，本轮投资的最大价值是**用小额资金买一组预先定义好成败标准的验证实验**（§8），而不是买确定的增长。

### 2.3 护城河：哪些成立、哪些不成立（不吹）

**不成立**：LLM+工具编排架构（可复制）、过程可视化（体验优势）、多语言（功能）。

**成立但需积累的**：
1. 跨境行业知识库/规则库——当前为空，靠真实客户案例冷启动，是先发者最难被抄的资产；
2. 前后对比纵向数据资产——诊断→整改→复查，免费工具都不做，直接驱动复查留存；
3. 服务承接闭环——商业模式护城河，与服务商网络共同构成双边效应雏形。

## 3. 竞争格局：三层夹击与回答

| 层 | 玩家 | 回答 |
|---|---|---|
| 免费 grader/审计 | HubSpot Grader、PageSpeed、Ahrefs/Semrush | 无跨境语境、无纵向追踪、无服务闭环 |
| 服务商人工诊断 | 同行顾问 | 我们是顾问的产能杠杆，不是替代品 |
| 通用 LLM / AI 建站 | ChatGPT/DeepSeek 直问、店匠等 | 纯 LLM 无事实检测层；确定检测 + LLM 解读可复现可验证 |

「AI 网站审计」品类 2026 年正在拥挤化（SavageAudit、LeakAudit 已出现）——窗口期约 12–24 个月，这是本轮融资的时间理由。

## 4. 财务预测（bottom-up，全部为假设模型，供压力测试）

关键假设：ACV ¥2.4 万；试点→付费转化 30%；销售周期 1–2 个月；毛利率 >95%。

| 年度 | 付费服务商 | ARR | 关键动作 |
|---|---|---|---|
| Y1（融资后 12 个月） | 20 家 | ≈¥48 万 | 90 天试点验证 → 单行业模板库 → 渠道起步 |
| Y2 | 100 家 | ≈¥240 万 | 白标分销、前后对比留存、3 个行业纵深 |
| Y3 | 300 家 + 服务撮合试点 | ≈¥720 万+ | 扩展层实验、Pre-A/A 轮 |

悲观情形（0.5x）：Y2 仅 40 家付费 → 滩头生意仍自负盈亏，但扩张故事不成立，应收缩为现金流工具公司。
乐观情形（1.5x）：Y2 150 家 + 复购率 >80% → 启动交易层，切换估值叙事。

**资金需求（占位，可按创始人实际诉求调整）**：天使轮 ¥300–500 万，18 个月 runway。
用途：40% 工程（测速节点、白标、前后对比、API）· 35% GTM 与试点交付 · 15% 第三方数据/API 与模型成本 · 10% 缓冲。

## 5. 风险（按致命程度，诚实排序）

| # | 风险 | 缓解与验证 |
|---|---|---|
| 1 | 免费替代 + 通用 LLM 稀释（致命） | 试点期 concierge 对照实验：平台报告 vs 免费工具 vs ChatGPT，服务商盲选 |
| 2 | 报告太通用（致命） | 单行业模板库 + 顾问盲测，专业率 ≥70% 为过关线 |
| 3 | 获客成本 / 渠道不达（高危） | 服务商直销试点本身即验证；终端投放仅作证伪实验 |
| 4 | 服务承接依赖合作方（高危） | 白标 + 分成绑定头部服务商 |
| 5 | 测速不准等工程项（中危） | 接第三方全球测速 API |
| 6 | 模型成本（低危） | 限额 + 缓存 |

**证据层级声明**：夸奖 < 口头意向 < LOI < 预付 < 重复购买。当前本项目无付费证据——本轮融资的 ask 就是购买把证据推过 LOI 与预付线所需的 90 天。

## 6. 90 天里程碑（本轮资金对应的可检验承诺）

1. 约谈 10–15 家服务商，≥1 家付费或书面付费意向，≥3 家明确「会在获客/交付流程里用」；
2. 机械/工业品类 B2B 模板库 + 10 份真实报告盲测，顾问「专业」率 ≥70%；
3. 「重新诊断 + 前后对比」上线，试点用户 30 天复查率 ≥30%；
4. 终端 ¥99 付费 landing page 小额实验（证伪用，转化 <1% 即放弃终端线）。

**NO-GO 承诺**：若第 1、2 项同时失败，停止扩张叙事，向投资人如实复盘并讨论收缩/转型——钱怎么花、什么算失败，写在花钱之前。
